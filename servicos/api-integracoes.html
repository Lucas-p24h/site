O que você pode fazer

Endpoints disponíveis

📤

Enviar título para protesto

Envie dados do título e do devedor programaticamente. Receba o ID do protocolo para acompanhamento.

📞

Iniciar cobrança

Dispare o fluxo de cobrança extrajudicial via API com um único POST. Defina canais e prazo de escalonamento.

📊

Consultar status

Acompanhe em tempo real o status de cada título, etapa da cobrança e resposta do cartório.

🔔

Webhooks

Receba notificações em tempo real no seu sistema quando houver qualquer atualização no título.

🔍

Consulta de protestos

Consulte protestos de CPF ou CNPJ programaticamente e integre ao seu fluxo de análise de crédito.

📄

Emitir carta de anuência

Após o pagamento, emita a carta de anuência automaticamente via API sem intervenção manual.

Exemplo de uso

Integração em minutos

API simples, bem documentada e fácil de integrar em qualquer stack.

POST /v1/titulos

// Enviar título para protesto curl -X POST \ https://api.protesto24h.com.br/v1/titulos \ -H "Authorization: Bearer {seu_token}" \ -H "Content-Type: application/json" \ -d '{ "devedor": { "nome": "João Silva", "cpf": "123.456.789-00", "email": "joao@email.com" }, "valor": 1500.00, "vencimento": "2025-01-15", "servico": "cobranca_protesto" }'

Resposta

{ "id": "tit_abc123", "status": "cobranca_iniciada", "protocolo": "P24H-2025-001234", "webhook_url": "https://..." }
